A one-line excuse from the GPS for sending the driver down the wrong road: the map swore a cul-de-sac was a shortcut to a wedding, and the lake was never in its contract. `main.py` (stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
